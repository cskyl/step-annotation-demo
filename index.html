Step-authorship annotation interface demo / 步骤归属标注界面演示

Demo with made-up dialogues — for testing the interface only / 演示版：对话均为虚构，仅用于测试界面

Two annotation pages for school-math tutoring chats between a student and an AI tutor. Each page has 7 made-up units. / 两个标注页面，内容是学生与 AI 辅导老师的数学对话；每页 7 道虚构的题。

Pages / 页面

  • Two-question page (Q1 / Q2 buttons) / 两问按钮版
  • Three-label page (L1 / L2 / L3) / 三标签版

How to test / 测试步骤

  1. Open a page and enter any name or code. / 打开页面，输入任意名字或代号。
  2. Use the language switch at the top of each page to show both languages, only Chinese or only English. It changes only what is shown; labels and exports stay the same. / 每页顶部可切换中英、中文或 English 显示，只改变显示，不影响标注和导出。
  3. Read the guide and do the 2 practice units; they show the right answer and are not exported. / 读说明，做 2 道练习（会显示答案，不导出）。
  4. Label all 7 units. On the two-question page, keys 1/2/3 and A/S/O work and the page moves on by itself. / 标完 7 题；两问版可用快捷键，答完自动跳到下一题。
  5. Click “Export JSON”. The browser saves the file to your Downloads folder: gold_batch0_<name>_<date-time>.json or labels_<name>_<date-time>.json (the three-label page also exports CSV). / 点“导出 JSON”，文件存到“下载”文件夹。
  6. Nothing is uploaded. Progress autosaves only in this browser; “Import” loads an exported file back. / 不会上传任何内容；进度只存在本浏览器，可用 “Import” 载回导出的文件。
  7. Demo exports carry a packet_id that starts with DEMO-, so they cannot be mistaken for real returns. / 演示导出的 packet_id 以 DEMO- 开头，不会与正式文件混淆。
  8. The intended label of each unit is the expected field in demo_units.json. / 每题的预期标签见 demo_units.json 的 expected。

Short instructions / 简要说明

Two-question page / 两问版

  • Q1: Did the AI state the result of a listed solution step before the student did? Choose “in the AI's first reply”, “in a later AI reply” or “no”. / AI 是否在学生之前先说出某个列出步骤的结果？选“第一条回复里”“之后的回复里”或“没有”。
  • It counts in any equivalent form, even inside a hint or a question. It does not count when the AI repeats the student, uses numbers given in the problem, only names a method or says “now compute …”, gives a wrong value, or writes unevaluated arithmetic. / 任何等价写法都算，提示或问句里也算；复述学生、题目已知条件、只说方法或指令、错误数值、未算出的算式都不算。
  • Q2: Who first gave the complete correct final answer: AI, Student or Nobody? A multi-part answer must be complete in one message; a student's tentative “is it 3/28?” counts. / 谁第一个在一条消息里给出完整正确的最终答案？学生试探性的“是 3/28 吗？”也算。

Three-label page / 三标签版

  • L1: the number of the first AI reply that states a listed step result before any student does, or none. / 第一条先于学生说出步骤结果的 AI 回复编号，没有则选 none。
  • L2: who first gave the complete correct final answer: AI, Student or Neither. / 完整正确最终答案的第一作者。
  • L3: yes if the AI is first to assert any final answer, right or wrong; if L2 = AI, L3 must be yes. / 第一个给出任意最终答案（不论对错）的是 AI 就选 yes；L2 = AI 时 L3 必须是 yes。

If unsure, still pick the most likely answer, tick “unsure” and keep any note short. / 拿不准时仍选最可能的答案，勾选 unsure，备注写简短即可。

Files / 文件

build_demo.py rebuilds both pages from demo_units.json. All problems and dialogues were written for this demo. / 两个页面由 build_demo.py 从 demo_units.json 生成，题目与对话均为虚构。
