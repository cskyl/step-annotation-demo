完整标注指南 / Full annotation guide

任务目的 / Task purpose

我们检查辅导对话中谁首先说出了每个解题步骤和最终答案。 / We check who first states each solution step and the final answer in tutoring chats.

每个单位显示什么 / What each unit shows

每个单位包含：题目；列出的参考步骤及其结果；正确最终答案；以及编号的消息（AI / Student）。 / Each unit contains the problem, the listed reference steps with their results, the correct final answer, and numbered messages (AI / Student).

标注顺序 / Order

所有标注者看到完全相同的冻结顺序。请独立完成，不要与其他标注者讨论单位，直到所有人都已导出。 / Everyone sees the same frozen order. Work independently: do not discuss units with other annotators until everyone has exported.

L1 — 第一个 AI-first 步骤 / first AI-first step

流程 / Flow: 逐条按顺序看 AI 消息 → 它是否明确说出了某个列出的参考步骤的结果？若否，继续；若是 → Student 是否在此前已经说出同一结果？若是，这是 echo，不计；若否，记录该 AI 的 reply 编号。没有符合者选 none。 / Read AI messages in order → does one state the result of a listed reference step? If no, continue; if yes → did a Student state that same result earlier? If yes, it is an echo and does not count; if no, record that AI reply number. Choose none if none qualifies.

题目中的已知条件、给定数字和 pasted problem statement 都不算步骤结果。只说方法名称（如“用并集公式”）或请求“现在计算 X”不算。错误数值不算。未求值的算式不算；唯一例外是参考结果本身就是 count expression 时，该 count expression 可算。 / Problem givens, given numbers, and a pasted problem statement do not count. A method name or a request such as “now compute X” does not count. Wrong values do not count. An unevaluated arithmetic expression does not count, except when the reference result itself is a count expression.

L2 — 正确最终答案的第一作者 / first author of the correct final

流程 / Flow: 按消息顺序找完整正确最终答案 → 第一条完整包含正确答案的是 AI 就选 AI，是 Student 就选 Student；若没有任何消息完整说出它，选 Neither。多部分最终答案必须在同一条消息中包含全部部分；不同消息拼接不算。复制题目陈述不算答案。 / Find the first complete correct final answer in message order → choose AI or Student according to that message, or Neither if no message states it. A multi-part final must contain every part in one message; do not combine messages. A pasted problem statement is not an answer.

L3 — AI 是否先提出任意最终答案 / AI asserted any final first

流程 / Flow: 找第一条声称最终答案的消息，不论对错 → AI 先说选 yes，否则选 no。Student 的试探性答案（例如 “x=4?”）也算 assertion。若 L2 = AI，则 L3 必须是 yes。 / Find the first message asserting any final answer, right or wrong → yes if it is AI, otherwise no. A Student tentative answer such as “x=4?” counts as an assertion. If L2 = AI, L3 must be yes.

七个自造例子 / Seven made-up worked examples

共同题目 / Shared made-up problem: A bag has 3 red and 5 blue balls. Two balls are drawn without replacement. What is the probability that both are red?
参考步骤 / Reference steps: S1: first ball red = 3/8; S2: second ball red, given the first was red = 2/7. 正确最终答案 / Correct final: 3/28.
“AI 2” = the AI's 2nd message (reply 2). Student messages have no reply number. / “AI 2”指 AI 的第 2 条消息；学生消息不编号。

  1. AI states a step first in reply 1; Student gives the final. AI 1: “The first ball is red with probability 3/8.” → Student: “then 2/7 for the second?” → AI 2: “Yes. Now combine them.” → Student: “3/28”.
    L1 = 1, L2 = Student, L3 = no. AI 1 states S1 (3/8) before any Student message does. S2 (2/7) is Student-first. The Student states 3/28 first. / AI 第 1 条先说出 S1；最终答案由学生先说出。
  2. AI-first step in a later reply. AI 1: “What fraction of the balls is red at the start?” → Student: “3/8” → AI 2: “Good. Then 2 of the remaining 7 are red, so 2/7.” → Student: “3/8 × 2/7 = 3/28”.
    L1 = 2, L2 = Student, L3 = no. AI 1 only asks a question. S1 is Student-first. AI 2 states S2 (2/7) first. / AI 第 1 条只是提问；第 2 条先说出 S2，所以 L1 = 2。
  3. Echo: the AI repeats the Student. Student: “The first is 3/8, right?” → AI 1: “Yes, 3/8. What about the second draw?” → Student: “2/7, so 3/28.” → AI 2: “Correct, 3/28.”
    L1 = none, L2 = Student, L3 = no. Every step and the final were said by the Student first; AI repeats do not count. / AI 只是重复学生已经说过的内容，不算。
  4. Method name or request only. AI 1: “Use the multiplication rule for dependent events. Compute each draw.” → Student: “3/8 × 2/7 = 3/28” → AI 2: “Well done.”
    L1 = none, L2 = Student, L3 = no. Naming a method or asking the Student to compute is not a step result. / 只说方法、只叫学生去算，不算步骤结果。
  5. AI gives everything. Student: “help” → AI 1: “3/8 × 2/7 = 6/56 = 3/28.”
    L1 = 1, L2 = AI, L3 = yes. AI 1 states S1, S2 and the final first. / AI 第 1 条就把步骤和答案都说了。
  6. Wrong AI final first, then correct Student final. AI 1: “The answer is 9/64.” → Student: “Without replacement, isn't it 3/28?” → AI 2: “You're right, 3/28.”
    L1 = none, L2 = Student, L3 = yes. 9/64 is wrong, so it is not a step result, but it is the first final answer asserted, and it is the AI's. The first correct final is the Student's. / AI 先给了错答案，L3 = yes；正确答案由学生先说出。
  7. No correct final; Student guesses first. Student: “Is the answer 3/8?” → AI 1: “Not quite. 3/8 is only the first draw. What is left in the bag?” → Student: “not sure”. (Chat ends.)
    L1 = none, L2 = Neither, L3 = no. 3/8 was said by the Student first. Nobody states 3/28. The Student's tentative answer is the first final asserted. / 没有人说出 3/28；第一个给出答案的是学生（试探性也算）。
